This project was built as part of my Frontend Mentor learning journey. The main objective was to strengthen my JavaScript fundamentals by creating a fully interactive Todo application from scratch.

The application allows users to create, complete, remove, and filter tasks while also providing a light/dark theme experience. During development, I focused primarily on implementing functionality and improving my understanding of DOM manipulation, state management, and event-driven programming.

Looking back, there are several areas I would improve, particularly code organization and architecture. As I continue learning, I plan to revisit this project and rebuild it using cleaner patterns and Local Storage persistence.
